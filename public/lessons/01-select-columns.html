Picking columns with SELECT

Ask a table for just the columns you care about.

The idea

A table is a grid: every row is one thing (one customer) and every column is one fact about it (name, city…).

FROM customers says which table to read. SELECT name, city says which columns to keep. The database always reads FROM first, then trims to the columns you named.

What to watch

  • All 20 customer rows fly out of the customers table (pink).
  • In the SELECT step the chips shrink to just name and city — the other columns are cut away.
Tip. Column order in SELECT is the order you get back. Try SELECT city, name.
