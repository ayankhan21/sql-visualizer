SELECT * — every column

The star is a shortcut for "all columns".

The idea

* means "every column, in table order". It is handy for peeking at a table you have never seen.

Because nothing is being removed, the SELECT step has nothing to cut: rows go straight from the table to the result.

What to watch

  • Six department rows slide out of the departments table and land in the result unchanged.
Careful. In real applications avoid SELECT *: it drags every column across the network and breaks when someone adds a column.
