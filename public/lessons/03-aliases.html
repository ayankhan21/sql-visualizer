Renaming columns with AS

Give result columns friendlier names.

The idea

AS gives a column (or later, a table) an alias: a nickname used in the output. The data does not change — only the label does.

Aliases become essential once queries compute values or join tables that have columns with the same name.

What to watch

  • The result has the same cells as lesson 1, but the column headers read customer and home_town.
