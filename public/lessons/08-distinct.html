Removing duplicates with DISTINCT

Each different value once.

The idea

Several customers share a country, so SELECT country would repeat values. DISTINCT collapses identical rows into one.

What to watch

  • Duplicate chips merge into the first chip with the same value.
Tip. SELECT DISTINCT a, b removes duplicate pairs, not duplicate values of each column.
