Pattern matching with LIKE

Find text that looks like something.

The idea

LIKE compares text to a pattern. % stands for any run of characters and _ for exactly one character.

  • 'M%' — starts with M
  • '%son' — ends with "son"
  • '%an%' — contains "an"

What to watch

  • Rows whose names match neither pattern are dropped by WHERE.
