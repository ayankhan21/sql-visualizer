Calculated columns

Compute new values on the fly.

The idea

SELECT can contain expressions: arithmetic (+ - * /), functions like ROUND, UPPER, LENGTH… The result is computed per row; the stored table is untouched.

Computed columns have no source table, so they appear in a neutral grey instead of a table colour.

What to watch

  • A new grey cell appears on each chip in the SELECT step.
Your turn. The query is live — edit it and press Run. Colours tell you which table each cell came from. Use Reset data to undo any INSERT / UPDATE / DELETE.
