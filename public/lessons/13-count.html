Counting rows with COUNT

Collapse many rows into one number.

The idea

An aggregate function summarises many rows into one. COUNT(*) counts rows. Because a WHERE comes first, this counts only the delivered orders.

What to watch

  • Surviving rows stack up and then merge into a single chip holding the count.
Tip. COUNT(column) skips NULLs; COUNT(*) counts every row.
