Adding rows with INSERT

Create new rows in a table.

The idea

INSERT INTO table (columns) VALUES (…) appends rows. Columns you skip get their default (usually NULL) — here the id is filled in automatically with the next free number.

Everything lives in your browser's memory. Reset or a refresh restores the original data.

What to watch

  • Two green chips join the end of categories, then the table above flashes the new rows.
Tip. Each table is capped at 50 rows so the animations stay smooth.
Your turn. The query is live — edit it and press Run. Colours tell you which table each cell came from. Use Reset data to undo any INSERT / UPDATE / DELETE.
