Joining three tables

Chain joins: each ON links the next table.

The idea

Start with orders — it holds two foreign keys (customer_id, employee_id). Each additional JOIN pulls in one more table, widening the row.

Joins run left to right: orders+customers first, then that result joined with employees.

What to watch
