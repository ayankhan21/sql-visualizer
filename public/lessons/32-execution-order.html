The real order of a query

You write SELECT first, but SQL runs it almost last.

The idea

The logical order is:

  1. FROM / JOIN — build the working set
  2. WHERE — filter rows
  3. GROUP BY — bucket
  4. HAVING — filter buckets
  5. SELECT — compute columns
  6. ORDER BY — sort
  7. LIMIT — cut

This explains why you cannot use a SELECT alias in WHERE (it does not exist yet) but you can in ORDER BY.

What to watch
