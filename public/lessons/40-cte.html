Common Table Expressions (WITH)

Name a subquery to make queries readable.

The idea

WITH name AS (query) defines a temporary named result — a CTE — that the main query can use like a table. It reads top-down like a recipe: first compute the totals, then use them.

What to watch

  • The CTE is computed first (see the WITH row in Analyze), then joins to orders.
