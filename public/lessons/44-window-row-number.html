Window functions: ROW_NUMBER

Calculate across rows without collapsing them.

The idea

GROUP BY squashes rows. A window function adds a computed column but keeps every row. OVER (ORDER BY salary DESC) defines the "window" — here the whole table sorted by salary — and ROW_NUMBER() numbers the rows 1, 2, 3…

What to watch

  • With no PARTITION BY there is one window: the whole table.
  • WINDOW ORDER sorts the rows for the function, then COMPUTE fills the new ROW_NUMBER() column (grey) — every row is still there.
  • In the final SELECT the rows return to their original order, each keeping its number.
